# MUST Student Portal – Login and Sign-up Page

A responsive login and account creation page for the MUST Student Portal, built with plain **HTML** and **CSS** only (no JavaScript).

## Features

- Create account form (full name, email, password)
- Sign in form (email, password, "Forgot password?" link)
- Switches between the two forms using hidden radio buttons and CSS (`:checked`)
- Built-in form checks: required fields, valid email format, minimum 8-character password
- Two-panel layout with an image panel and a form panel
- Responsive design: the layout stacks on phones and tablets
- Commented code to explain what each part does
